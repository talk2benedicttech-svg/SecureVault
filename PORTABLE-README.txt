SecureVault portable Windows application

1. Copy the complete SecureVault folder to a USB drive.
2. On a Windows computer, open that folder and run SecureVault.exe.
3. Choose or create an encrypted vault and select the files/folders to back up.
4. Review and authorize each newly detected device in the app.

The application and Python runtime are bundled in this folder. No separate Python
installation or internet download is needed on the computer where you run it.

Keep the complete folder structure intact. The data folder stores this copy's
device allowlist and settings. Create the encrypted vault on the USB drive if the
backup destination should travel with the app. Vault contents remain encrypted.

Windows does not automatically launch programs from USB drives. Open the drive
and start SecureVault.exe yourself. Windows may show a SmartScreen prompt for an
unsigned app; only continue if you trust the copy you built.
